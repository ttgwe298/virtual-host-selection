## 虚拟主机到底适不适合你

虚拟主机也叫共享主机，是把一台物理服务器分隔成若干个「小主机」单独售卖，几个网站共用同一台服务器的 CPU、内存等资源，大多数情况下还共用同一个 IP。它的好处是便宜、省事，环境由服务商配好，你只管传网站程序；短板也明确：性能有限，扛不住大流量，基本用途就是托管个人博客、作品集和小型企业展示站。

经验判断是：日访问量几百、以图文内容为主，虚拟主机完全够；要做论坛、商城这类高并发应用，要么上独享虚拟主机，要么直接考虑 VPS。

还有一点决定方向：操作系统。Linux 主机跑 PHP 程序，对 WordPress、Discuz! 这类程序支持很好；Windows 主机跑 ASP/ASP.NET。市面上多数主机商以 Linux 主机为主，支持 Windows 主机的相对少。确认自己程序用什么语言开发，选择就少了一半。

## 国内还是海外：先解决备案再谈价格

国内和海外主机最大的差别在备案。国内虚拟主机需要完成 ICP 备案才能正式开通，要留出办理时间；香港、美国等海外主机购买后可直接托管网站，无需备案。部分国内服务商把备案服务打包进来，比如时代互联为虚拟主机用户提供免费备案、全程线上办理，还有 7 天免费试用。

不过免备案有代价。大陆访问中国香港、美国、新加坡等境外机房时，容易遇到国际链路拥塞，延迟和丢包会比较明显，这一点阿里云的官方帮助文档写得直白。所以决策逻辑很简单：客户主要在大陆、网站不急着上线，选国内主机加备案；网站要立刻上线，或者受众本身在海外，选海外主机，接受一定的速度损失。

## 共享还是独享：多数购买指南不讲透的决策规则

共享和独享虚拟主机的差别，用阿里云官方的对比表一目了然，核心就三个字：独享还是共享。

| 对比项 | 共享版虚拟主机 | 独享版虚拟主机 |
| --- | --- | --- |
| 带宽 | 共享 | 独享，网速更稳定 |
| IP | 共享 | 独立，更易做推广 |
| 网站流量 | 有限制 | 不限 |
| CPU 和内存 | 共享 | 独享，运行更快 |

翻译成决策规则：

- 要长期做 SEO、投广告、在平台做推广：选独立 IP 的方案，共享 IP 下同服务器其他网站出问题可能牵连你
- 担心流量超限、高峰期变慢：独享版的独享带宽和不限流量更稳
- 纯展示站、预算压到最低：共享版年付就是最便宜的选择
- 拿不准要不要长期用：独享版支持月付，先买一个月试，试错成本低

还有一个很多人买完才发现的坑：操作系统不能随便换。部分主机受硬件、机房位置等限制，不支持更改系统，比如阿里云非中国内地地域的增强版独享主机就无法切换成 Windows。而操作系统和程序语言是绑定的：Windows 主机对应 ASP、ASP.NET 和 ACCESS、SQL Server 数据库（增强版独享支持 ASP.NET Core 6.0）；Linux 主机对应 PHP 和 MySQL、SQLite。跑 WordPress、Discuz! 选 Linux；跑 ASP/.NET 开发的程序选 Windows。下单前确认清楚，别指望事后切换。

## 购买流程与三个常见的坑

主流购买流程大同小异，以阿里云为例大致六步：注册账号，进入虚拟主机管理页面点「创建主机」，选机房，选产品配置，选操作系统，选时长付款。机房按就近原则选，客户集中在华北选北京或青岛，华东选杭州或上海，华南选深圳，西南选成都，离客户越近访问越快。付款成功后，主机一般 5 到 10 分钟内自动创建完成。

坑主要集中在三处：

1. **没有初始密码。** 出于安全考虑，服务商不会预置密码。主机创建后要先初始化管理控制台登录密码、FTP 密码和数据库密码，规则是 8~20 个字符，大写字母、小写字母、数字、特殊符号四类里至少占三类。不做初始化，主机没法正常使用。
2. **未支付的订单不会消失。** 付款中途关掉支付页面，订单会保留在「未支付订单」里，之后可以继续支付，不用重新下单。
3. **免费域名要按顺序领。** 提供免费域名的服务商（如 GoDaddy）要求在购买主机付款前先把域名加入购物车，顺序反了可能领不到。

## 常见问题

### 虚拟主机和 VPS 是一回事吗？

不是。虚拟主机是一台物理服务器分隔出的若干份额，多用户共享 CPU、内存，通常还共享 IP；VPS 则把 CPU、内存、存储完全分隔，每台有独立 IP，能当独立服务器用。放个小站，虚拟主机更便宜；要跑需要独享资源的应用，选 VPS。

### 买虚拟主机一年要花多少钱？

入门门槛很低：共享主机首年 1 元（中资源普及型）、每月 17 元（GoDaddy 经济版）都有。但首年价通常只是续费价的零头，做预算要按续费价算，比较现实的预期是每年几百元。

### 海外主机不备案真的能用吗？

能用。香港、美国等海外主机购买后可直接托管网站，没有备案环节。代价是速度：大陆访客走国际链路，延迟和丢包可能比较明显，受众以海外为主或对速度要求不高时更合适。
